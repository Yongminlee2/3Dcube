# 실기기 확인 목록 — Phase A

자동화할 수 없는 것들이다. 스와이프의 "손에 붙는 느낌"은 기계가 판단할 수 없고,
터치 입력을 흉내 내는 비용은 얻는 것에 비해 크다.

테스트 기기: Galaxy S20 Ultra (SM-G988N), adb 시리얼 `R3CN50JXF9E`

## 빌드

이 PC의 Unity는 한글 경로(`C:\Users\사용자\...`)에 설치돼 있어서 환경 변수 없이는 빌드가 실패한다.

```bash
TEMP="C:/workAndroid/tmp-ascii" TMP="C:/workAndroid/tmp-ascii" GRADLE_USER_HOME="C:/workAndroid/gradle-home-ascii" "C:/Users/사용자/AppData/Local/Unity/Editors/6000.3.18f1/Editor/Unity.exe" -batchmode -quit -nographics -projectPath "C:/workAndroid/3Dcube" -executeMethod CubeEditor.BuildScript.BuildApk -logFile "C:/workAndroid/3Dcube/build.log"
```

자세한 배경은 [한글 경로 함정](ascii-path-trap.md)을 볼 것.

## 설치

**폰이 연결되어 있고 사용자가 요청했을 때만 설치한다.** adb를 미리 띄워 두고 기다리지 않는다.

```bash
"C:/workAndroid/sdk-ascii/platform-tools/adb.exe" -s R3CN50JXF9E install -r "C:/workAndroid/3Dcube/Build/cube.apk"
```

## 조작

- [ ] 3×3에서 스와이프로 의도한 층이 의도한 방향으로 돈다
- [ ] 4×4에서도 의도한 층이 돈다 (칸이 작아 오조작이 늘어나는 지점)
- [ ] 2×2에서도 정상 동작한다
- [ ] 큐브를 여러 각도로 굴린 뒤에도 스와이프 방향 감각이 유지된다
- [ ] 드래그 중 축이 흔들려 바뀌지 않는다
- [ ] 45도를 넘기면 붙고, 못 넘기면 되돌아온다. 손을 뗄 때 화면이 튀지 않는다
- [ ] 배경을 끌면 큐브 전체가 굴러가고 상태는 변하지 않는다
- [ ] 노테이션 버튼이 스와이프와 같은 결과를 낸다
- [ ] 빠르게 연속으로 돌려도 밀리거나 어긋나지 않는다

조작이 뻑뻑하거나 예민하면 코드를 고치지 말고 `Assets/Resources/TouchInputSettings.asset`의
값을 조정할 것 — 드래그 시작 거리, 스냅 각도, 픽셀당 각도, 터치 여유 반경이 거기 있다.

## 화면

- [ ] 전개도가 3D 큐브와 항상 같은 상태를 보여준다
- [ ] 다크·라이트 두 테마에서 전개도와 글씨가 잘 읽힌다
- [ ] 한글이 깨지지 않는다 (깨지면 Phase D에서 OFL 한글 폰트를 넣는다)
- [ ] 세로로 고정되어 있고 가로로 눕지 않는다
- [ ] 뒤로가기 버튼이 홈으로 가고, 홈에서 앱이 닫힌다

## 흐름

- [ ] 섞기 → 풀기 → 자동 완성 감지 → 기록 저장이 끊기지 않는다
- [ ] 인스펙션을 켜면 15초가 세어지고, 첫 회전에서 계측이 시작된다
- [ ] 15초를 넘겨도 벌점 없이 첫 회전을 기다린다
- [ ] 기록 화면에 최고·ao5·ao12가 맞게 나온다
- [ ] 앱을 껐다 켜도 기록이 남아 있다
- [ ] 설정 변경이 저장되고 다시 켜도 유지된다
- [ ] 홈의 [배우기]를 누르면 "준비 중" 안내만 뜬다

## 학습 모드 (Phase B)

- [ ] 홈에서 [배우기]가 열리고, 2×2/4×4를 고른 상태면 "3×3부터"라고 안내한다
- [ ] 처음에는 1단계만 열려 있고 나머지는 잠겨 있다
- [ ] 설명 문단을 이전/다음으로 넘길 수 있고 글이 화면 밖으로 넘치지 않는다
- [ ] 공식 카드를 누르면 큐브가 그 공식을 돌린다
- [ ] 시연 중에는 손가락으로 큐브를 돌릴 수 없다
- [ ] [큐브 되돌리기]로 완성 상태로 돌아온다
- [ ] [연습하기]를 누르면 그 단계 직전 상태가 된다
- [ ] 단계를 맞추면 통과 문구가 뜨고 다음 단계가 열린다
- [ ] 앱을 껐다 켜도 진도가 남아 있다
- [ ] 공식 모아보기에서 아무 공식이나 시연할 수 있다
- [ ] 색이 아래 흰색·위 노랑·왼쪽 빨강·오른쪽 주황으로 보인다

## 힌트 (Phase C)

- [ ] 연습 화면에서 [힌트]를 누르면 다음 수와 이유가 한 줄로 뜬다
- [ ] 전개도에 지금 봐야 할 조각이 강조된다
- [ ] 힌트 줄을 누르면 그 수를 대신 둬 준다
- [ ] 힌트를 계속 따라가면 큐브가 실제로 풀린다
- [ ] 섞거나 초기화하면 들고 있던 힌트가 사라진다
- [ ] 2×2/4×4에서는 "3×3에서만 됩니다"라고 알린다
- [ ] 힌트가 뜨는 데 폰에서 1초 이상 걸리지 않는다

## 성능

- [ ] 4×4에서도 회전이 부드럽다 (눈에 띄는 끊김이 없다)
- [ ] 앱 시작이 3초 안에 끝난다

## 주의

앱을 지웠다 다시 깔아도 **기록이 되살아난다** — 안드로이드 자동 백업 때문이며 의도한 동작이다.
깨끗한 상태로 시험하려면 재설치가 아니라 설정에서 **앱 데이터 삭제**를 해야 한다.
