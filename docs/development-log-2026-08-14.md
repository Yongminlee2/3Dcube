# 2026-08-14 개발일지

## 작업 목표

갤럭시 실기기에서 확인된 카메라 색상 인식과 6면 방향 혼동을 줄이고, 연습·학습 화면의 조작 밀도와 큐브 위치를 정리했다. 큐브 스킨 진입 경로와 배경음·효과음 설정도 앱 흐름에 통합했다.

## 구현 내용

### 실물 큐브 촬영과 색상 인식

- 카메라 미리보기와 검출 영역을 같은 정사각형 크롭으로 통일했다.
- 각 칸을 7×7 영역의 중앙값으로 읽고, 여러 프레임의 시간축 중앙값을 사용해 손떨림·반사광·자동 노출 변화의 영향을 줄였다.
- 촬영한 작은 면에는 재분류된 스킨색이 아니라 카메라가 읽은 원본 RGB를 그대로 표시하도록 수정했다.
- 54개 스티커를 전체적으로 비교해 각 색이 정확히 9칸씩 배정되도록 균형 분류를 적용했다.
- 빨강·주황의 색상각 차이를 강화하고, 어두운 유색 스티커를 흰색으로 오판하지 않도록 중심색 판정을 보완했다.
- 중심색이 예상과 다르면 경고하되, 카메라 오판일 경우 사용자가 한 번 더 눌러 그대로 저장할 수 있게 했다.
- 촬영 순서를 `앞 → 위 → 아래 → 왼쪽 → 오른쪽 → 뒤`로 변경했다.
- 첫 앞면을 기준으로 매 단계에 중심색과 `위·왼쪽·오른쪽·아래` 이웃색을 크게 표시해 좌우 반전과 면 회전을 방지했다.
- 아직 촬영하지 않은 면으로 순서를 건너뛰지 못하게 하고, 촬영한 면은 선택해 다시 찍을 수 있게 유지했다.

### 연습·학습 화면

- 3×3 노테이션 패드에서 `2회`, `넓은 수` 토글을 제거하고 U/D/L/R/F/B와 `반시계`를 한 줄로 정리했다.
- 학습 단계의 연습 모드에도 노테이션 패드를 연결해 직접 큐브를 조작할 수 있게 했다.
- 힌트는 큐브를 자동으로 움직이지 않고 다음 동작과 방향만 설명하도록 유지했다.
- 연습 화면 카드와 하단 작업 버튼의 폭·높이·글자 크기를 통일했다.
- 학습 설명 중 큐브와 코치 카드, 페이지 버튼을 아래로 조정하고 연습 모드에서는 큐브를 더 크게 표시했다.
- 화면을 나가는 중이던 큐브 회전 애니메이션이 남지 않도록 회전기 생명주기를 보완했다.

### 홈·스킨·소리 설정

- 홈 화면에 `큐브 스킨` 바로가기를 추가하고, 홈에서 들어간 경우 홈으로 돌아오도록 복귀 경로를 보존했다.
- 스킨 미리보기 큐브를 카드 중앙에 맞췄다.
- 런타임 생성 방식의 잔잔한 배경음, 버튼 클릭음, 큐브 회전음, 완성음을 추가했다.
- 설정 화면에 배경음과 효과음 켜기/끄기를 추가하고 `PlayerPrefs`에 저장했다.
