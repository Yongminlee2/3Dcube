# 2026-08-12 개발일지

## 작업 목표

실제 Galaxy A16에서 사용하기 편하도록 3D 큐브의 조작, 힌트, 실물 큐브 입력, 연습 화면 UI와 앱 브랜딩을 마무리했다.

## 구현 내용

### 실물 큐브 카메라 입력

- 휴대폰 후면 카메라로 큐브의 여섯 면을 차례로 촬영하는 흐름을 추가했다.
- 각 면을 3×3 격자로 표본 추출해 중심색과 비교하고 U/F/R/B/L/D 상태로 변환한다.
- 촬영 순서, 현재 진행률, 면별 미리보기와 다시 촬영 기능을 제공한다.
- 자동 인식 결과가 잘못된 경우 전개도에서 직접 색을 수정할 수 있다.
- 카메라 권한 거부, 카메라 미지원, 초기화와 화면 이탈 시 자원 해제를 처리했다.
- 색상 거리, 회전·미러 UV 변환과 상태 생성 로직에 테스트를 추가했다.

### 힌트와 조작 개선

- 힌트를 누르면 큐브가 자동으로 움직이던 방식을 없애고 사용자가 직접 따라 할 동작을 설명하도록 변경했다.
- 앱에 없는 전체 큐브 회전 표기 `y`, `y2`, `y'`를 실제 U/D/L/R/F/B 조작으로 치환한다.
- 첫 동작을 `오른쪽 면을 시계 방향으로 한 칸`처럼 한국어로 안내한다.
- 한 손가락은 큐브 면 회전, 두 손가락은 큐브 시점 조절로 분리했다.
- 시점 이동 후에도 큐브의 세로축이 좌우로 기울지 않도록 pitch/yaw 기반 회전으로 정리했다.
- 노테이션 패드에 `반시계`, `2회`, `넓은 수` 토글을 추가하고 배치를 정리했다.

### 연습 화면 디자인

- 힌트 영역을 설명 카드로 바꾸고 현재 표기와 조작 설명을 함께 보여준다.
- 하단 동작 버튼을 아이콘이 포함된 4분할 툴바로 재구성했다.
- 섞기, 힌트, 되돌리기, 초기화 아이콘 리소스를 추가했다.
- 큐브와 전개도, 힌트, 노테이션 패드가 Galaxy A16 세로 화면에 맞도록 간격을 조정했다.

### 브랜딩과 앱 설정

- 앱 표시 이름을 `3D 큐브`로 변경했다.
- 선택한 3D 큐브 앱 아이콘을 Android 아이콘 리소스에 반영했다.
- Galaxy A16에서 다크·라이트 테마와 주요 화면을 순회 점검했다.

- 공식 목록 스크롤 제스처가 큐브 시점 회전에도 전달되지 않도록 입력 영역을 분리한다.
- Unity UI가 TalkBack에 개별 버튼·문구로 노출되도록 접근성 계층을 추가한다.
- 기록이 없을 때 삭제 버튼을 비활성화하고 잠긴 단계의 보조 글자 대비를 높인다.
- 실제 큐브 여섯 면을 모두 촬영해 다양한 조명에서 색상 인식 정확도를 추가 검증한다.
