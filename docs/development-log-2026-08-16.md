# 2026-08-16 개발일지

## 작업 목표

한 면의 9조각이 한 장의 그림을 이루는 일러스트 스킨을 섞은 뒤에도 실제로 완성할 수 있도록 조각 위치와 방향 판정을 보강한다. 배우기 흐름, 화면 터치 범위, 앱 아이콘을 함께 정리하고 Galaxy A16에 최종 빌드를 설치해 검증한다.

## 구현 내용

### 일러스트 스킨 조각과 방향 추적

- 일러스트 조각을 현재 좌표가 아니라 큐비의 고유 색 조합에 따라 배치해, 섞기 전후와 저장 상태 복원 후에도 같은 조각 이미지가 유지되게 했다.
- 각 면의 가운데 조각은 항상 해당 일러스트의 가운데 타일을 사용하도록 매핑을 고쳤다.
- 큐비마다 `0°`, `90°`, `180°`, `270°` 방향을 기록하고 층 회전 결과에 따라 방향을 갱신한다.
- 한 장 그림 방식에서는 색만 모두 맞아도 그림 방향이 틀리면 완성으로 처리하지 않는다. 조각 위치와 방향까지 원래 상태여야 기록 저장과 단계 완료가 발생한다.
- 저장 버전을 올리고 `ArtworkPending` 상태를 추가해, 색은 맞았지만 그림 방향이 남은 상태도 앱 재진입 후 이어서 풀 수 있게 했다.
- 앱에서 만든 섞기는 섞기 수식과 사용자가 실행한 이력을 재생해 정확한 3D 자세를 복원한다.

### 일러스트 스킨 전용 힌트

- 한 장 그림 스킨에서는 축약된 실제 이동 이력을 역순으로 계산해 색뿐 아니라 그림 방향까지 원상 복구되는 힌트를 제공한다.
- 긴 공식은 최대 12동작 단위로 보여주며, 일부만 입력하고 힌트를 다시 눌러도 이미 수행한 동작으로 되돌아가지 않고 현재 남은 구간부터 이어진다.
- 의미 없이 서로 상쇄되는 반복 동작은 축약한 뒤 안내한다.
- 실물 큐브 촬영 상태는 색 정보만으로 스티커 그림의 회전 방향을 알아낼 수 없으므로, 그림 방향까지 보장하는 경로는 앱에서 생성한 섞기에 적용한다.

### 배우기 흐름 개선

- 단계 설명과 연습 중 힌트를 실제로 따라 할 수 있는 구체적인 안내로 보강했다.
- 연습 목표를 달성하면 화면 안에 `다음 단계` 버튼을 표시해 목록으로 돌아가지 않고 바로 다음 단계로 이동할 수 있게 했다.
- 마지막 단계를 마치면 배우기 목록으로 돌아가는 완료 동작을 제공한다.

### 터치 범위와 안전 영역

- 큐브 회전을 막는 영역을 화면 하단 전체가 아니라 실제 버튼, 선택 항목, 스크롤 영역으로 제한했다.
- 버튼이 없는 하단 공간에서는 기존처럼 큐브 시점을 움직일 수 있고, 버튼을 누를 때만 큐브가 함께 움직이지 않는다.
- 두 손가락 조작 중 하나라도 UI에서 시작한 경우 큐브 제스처로 처리하지 않아 오작동을 줄였다.
- Android 시스템 내비게이션 영역과 하단 버튼이 겹치지 않도록 안전 영역에 하단 여유 공간을 추가했다.

### 앱 아이콘

- 선택한 홀로그램 3D 큐브 이미지를 Android 앱 아이콘으로 적용했다.
- 기존 아이콘을 자동으로 다시 그리지 않고 선택된 PNG를 그대로 사용하도록 아이콘 생성 경로를 수정했다.
- 아이콘 임포트 압축을 해제해 빌드 과정에서 작은 크기로 표시될 때의 번짐을 줄였다.
