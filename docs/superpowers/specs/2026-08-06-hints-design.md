## 1. 목표

**막힌 사람에게 다음 한 수를 알려준다.** 그리고 실물 큐브를 든 사람이 자기 큐브 상태를 앱에 넣을 수 있게 한다.

## 2. 제가 내린 결정과 그 이유

### 2.1 힌트는 Phase B가 가르친 방법을 따른다

최단 풀이(Kociemba 같은 최적 솔버)를 내지 않는다. 20수짜리 최적 해답은 **배우는 사람에게 아무것도 가르치지 못한다.** 왜 그 수를 두는지 설명할 수 없기 때문이다.

힌트는 LBL 7단계를 따라간다. 지금 상태가 몇 단계인지 판정하고(Phase B의 `StageChecker`), 그 단계를 진행시키는 수를 알려주고, **왜 그런지 한 줄로 설명한다.**

### 2.2 단계마다 방식이 다르다

| 단계 | 힌트 방식 |
|---|---|
| 4~7 (마지막 층) | **경우 인식.** 위층 모양을 보고 어느 경우인지 판정해 정해진 공식을 준다. 탐색이 필요 없다 |
| 1~3 (아래·가운데) | **조각 단위 탐색.** 다음에 놓을 조각을 고르고, 그 조각만 제자리로 보내는 짧은 수를 찾는다 |

마지막 층부터 만드는 이유: 경우가 유한하고 공식이 이미 Phase B에 있다. 탐색 없이 정확한 힌트가 나온다.

### 2.3 실물 큐브 입력은 수동 색 입력만

카메라 스캔은 조명·색보정 문제가 앱의 나머지 전부보다 크다. 전개도에서 칸을 눌러 색을 고르는 방식으로 한다. 카메라는 필요해지면 나중에 붙인다.

## 3. 범위

### 포함

- `CubeValidator` — 임의의 색 배치가 풀 수 있는 큐브인지 판정
- 마지막 층(4~7단계) 경우 인식과 힌트
- 1~3단계 조각 단위 힌트
- 힌트 UI — 다음 수, 한 줄 설명, 전개도에서 해당 조각 강조
- 실물 큐브 수동 색 입력 화면

### 포함하지 않음

- 최단 풀이 솔버 (Kociemba, 신의 수)
- 카메라 스캔
- 2×2·4×4 힌트 — 3×3이 자리 잡은 뒤
- 출시 준비물 (Phase D)

## 4. CubeValidator

임의의 칸 색 배열이 **실제로 조립 가능한 큐브인지** 판정한다. 사용자가 손으로 넣은 색은 오타가 있을 수 있고, 그대로 솔버에 넣으면 영원히 답을 못 찾는다.

일곱 가지를 본다.

| # | 검사 | 걸리는 실수 |
|---|---|---|
| 1 | 각 색이 정확히 9칸 | 색을 잘못 셈 |
| 2 | 센터 6개가 서로 다른 색 | 센터 오타 |
| 3 | 모서리 8개의 색 조합이 전부 유효하고 중복 없음 | 불가능한 모서리 |
| 4 | 엣지 12개의 색 조합이 전부 유효하고 중복 없음 | 불가능한 엣지 |
| 5 | 모서리 비틀림 합 ≡ 0 (mod 3) | 모서리 하나만 돌려 끼움 |
| 6 | 엣지 뒤집힘 합 ≡ 0 (mod 2) | 엣지 하나만 뒤집어 끼움 |
| 7 | 모서리 순열 홀짝 == 엣지 순열 홀짝 | 두 조각만 맞바꿈 |

5·6·7은 눈으로 절대 알 수 없는 종류다. 스티커를 뜯어 붙인 큐브가 이 셋 중 하나에 걸린다.

**결과는 왜 걸렸는지까지 돌려준다.** "이 큐브는 맞출 수 없습니다"만으로는 사용자가 어디를 고쳐야 할지 모른다.

## 5. 테스트 전략

`CubeValidator`는 성질 기반으로 검증할 수 있다.

- 완성 상태와 **어떤 스크램블 결과도** 항상 유효하다
- 스티커 두 개를 맞바꾸면 유효하지 않다
- 모서리 하나를 비틀면 유효하지 않다 (검사 5)
- 엣지 하나를 뒤집으면 유효하지 않다 (검사 6)
- 조각 두 개를 맞바꾸면 유효하지 않다 (검사 7)
- 각 실패마다 이유가 정확히 지목된다

힌트 쪽은 더 강한 성질로 검증한다 — **힌트를 따라가면 실제로 풀린다.** 임의의 스크램블에서 시작해 힌트가 주는 수를 계속 적용하면 유한한 횟수 안에 완성되어야 한다. 이 테스트 하나가 힌트 로직 전체를 덮는다.

## 6. 완료 기준

- [ ] `CubeValidator`가 일곱 검사를 전부 수행하고 이유를 돌려준다
- [ ] 마지막 층 경우 인식이 정확하다
- [ ] 힌트를 따라가면 임의의 스크램블이 완성된다 (테스트로 검증)
- [ ] 힌트 화면에서 다음 수와 이유가 보이고 전개도에 조각이 강조된다
- [ ] 실물 큐브 색을 손으로 넣을 수 있고, 잘못된 배치는 이유와 함께 거부된다
- [ ] 출시 준비물은 포함하지 않는다
