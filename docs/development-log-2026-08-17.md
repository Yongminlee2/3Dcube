## 작업 목표

일반 색상 스킨과 한 면 일러스트 스킨의 힌트 방식이 서로 달라 풀이 길이와 안내가 불규칙해지는 문제를 해결한다. 색상 풀이가 끝난 뒤 그림 방향 단계가 남는다는 사실을 사용자가 놓치지 않도록 스킨 선택과 연습 화면에 안내 팝업을 추가한다.

## 구현 내용

### 일반·그림 스킨 힌트 통일

- 캐릭터·일러스트 스킨도 일반 스킨과 동일하게 현재 큐브 상태를 분석하는 LBL 단계 공식을 사용하도록 변경했다.
- 섞기와 사용자의 이동 이력을 통째로 역순 재생하던 그림 스킨 전용 힌트를 제거했다.
- 사용자가 100회 이상 임의로 돌려도 힌트 길이가 이동 이력에 비례하지 않고 현재 큐브 상태와 풀이 단계에 따라 결정된다.
- 공식 일부를 실행한 뒤 힌트를 다시 눌러도 이미 수행한 동작으로 돌아가지 않고 같은 공식의 남은 부분을 유지한다.

### 그림 센터 방향 공식

- 일반 LBL 공식으로 색상과 조각 위치를 먼저 맞춘 뒤, 그림 가운데 방향만 남았을 때 별도의 picture-cube 공식을 제공한다.
- 센터의 `0°`, `90°`, `180°`, `270°` 방향을 읽어 색상 배치를 바꾸지 않는 보정 공식의 최소 조합을 계산한다.
- 한 센터 180도, 인접한 두 센터의 반대 방향 90도 보정 공식을 조합하며 사용자의 과거 이동 기록에는 의존하지 않는다.
- 물리적으로 만들 수 없는 센터 하나만 90도 돌아간 상태에서는 잘못된 공식을 생성하지 않는다.

### 그림 단계 안내 팝업

- 이미지 스킨을 선택하면 `이미지 스킨 안내` 팝업을 표시한다.
- `한 면 전체`는 색상 완성 후 그림 방향 공식이 추가되고, `조각마다 반복`은 일반 큐브처럼 색상만 맞추면 끝난다는 차이를 설명한다.
- 연습 중 색상이 모두 맞았지만 그림 방향이 남으면 `색상 큐브 완성!` 팝업을 자동 표시한다.
- 팝업의 `그림 공식 보기`를 누르면 현재 그림 센터 방향에 맞는 공식이 바로 힌트 카드에 나타난다.
- 같은 풀이에서 그림 단계 팝업이 반복해서 나타나지 않도록 상태를 관리하고, 그림 단계에서 앱을 나갔다 돌아오면 필요한 안내를 다시 표시한다.

### 테스트 격리

- 이미지 스킨 선택 테스트가 다음 렌더링 테스트의 색상 설정에 영향을 주지 않도록 스킨과 배치 설정을 테스트 전후로 복원한다.
- 색상 머티리얼을 검증하는 테스트는 항상 텍스처가 없는 일반 스킨에서 실행하도록 고정했다.

## 후속 작업 참고

- 색상 풀이 공식은 `HintEngine`, 그림 센터 방향 보정은 `ArtworkCenterSolver`가 담당한다.
- 연습 화면은 색상 상태가 완성되고 `CubeRenderer.IsSolvedWithArtwork()`가 거짓인 순간에만 그림 단계 팝업을 표시한다.
