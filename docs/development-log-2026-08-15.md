# 2026-08-15 개발일지

## 작업 목표

실물 큐브를 촬영한 뒤 나중에도 이어서 풀 수 있는 흐름을 완성하고, 사용자가 힌트만 따라가도 3×3 큐브를 끝까지 맞출 수 있도록 힌트의 정확성과 연속성을 보강한다. 캐릭터·일러스트 스킨, 큐브 회전 효과음, 연습·배우기 화면의 조작 경험도 함께 개선한다.

## 구현 내용

### 연속해서 따라가는 3×3 힌트

- 힌트를 누르면 큐브를 자동으로 움직이지 않고, 사용자가 직접 입력할 전체 남은 공식을 영문 기호로 표시하도록 유지했다.
- 공식 일부를 실행한 뒤 힌트를 다시 눌러도 과거 공식으로 돌아가지 않고, 아직 실행하지 않은 남은 수식만 그대로 이어서 보여주도록 힌트 계획을 유지한다.
- 안내와 다른 동작을 입력한 경우에만 현재 큐브 상태를 기준으로 새 해결 경로를 계산한다.
- `U U'`, `U U U U`처럼 상쇄되는 반복은 제거하고, 같은 면 두 번은 `U2`처럼 읽기 쉽게 정리한다.
- 화면에 `2회` 버튼이 없어도 `U2`는 같은 면 버튼을 두 번 눌러 실행할 수 있다.
- 서로 다른 10개의 결정적 스크램블에서 화면에 표시된 영문 힌트만 순서대로 실행해 완성 상태에 도달하는 테스트를 추가했다.
- 공식의 앞부분만 실행하고 힌트를 다시 눌렀을 때 정확한 나머지 수식이 유지되는 회귀 테스트를 추가했다.

### 연습·배우기 이어하기와 안전한 조작

- 연습, 배우기 연습, 실물 큐브 촬영 후 진입한 큐브 상태를 저장하고 뒤로 갔다가 다시 들어와도 이어서 할 수 있도록 진행 상태 저장소를 추가했다.
- 섞기와 초기화는 즉시 실행하지 않고 확인창을 거치도록 바꿔 실수로 진행 상태를 잃지 않게 했다.
- 배우기 화면에서도 U/D/L/R/F/B와 반시계 조작을 사용할 수 있게 유지하고, 큐브와 설명·이전·다음 영역의 간격을 조정했다.
- 화면을 나가는 순간 진행 중이던 회전 애니메이션을 안전하게 마무리해 재진입 시 조작이 멈추거나 반쯤 돌아간 상태가 남지 않게 했다.

### 실물 큐브 촬영과 색상 안내

- 카메라 미리보기와 검출 영역을 같은 정사각형으로 맞추고, 촬영 안내가 큐브 위에 겹치지 않도록 정리했다.
- 앞면부터 시작해 위·아래·왼쪽·오른쪽·뒤 순서로 촬영하도록 중심색과 방향 안내를 보강했다.
- 조명과 노출 변화에서 빨강·주황, 노랑·흰색이 뒤바뀌는 문제를 줄이도록 색상 균형과 중심색 판정을 보완했다.
- 촬영된 원본 색과 전개도 미리보기 색이 다르게 보이지 않도록 원본 샘플 색 표시 경로를 분리했다.
- 카메라가 중심색을 오인했을 때 사용자가 확인 후 촬영을 계속할 수 있도록 예외 흐름을 마련했다.

### 캐릭터·일러스트 스킨

- 귀여운 캐릭터와 여름·별빛·리조트 콘셉트 스킨 4종을 추가하고 캐릭터 스킨을 목록 아래쪽에 배치했다.
- 한 조각마다 같은 그림을 반복하는 방식과, 한 면의 9개 조각을 합치면 한 장의 일러스트가 되는 방식을 스킨 화면에서 선택할 수 있게 했다.
- 윗면과 아랫면의 이미지 방향이 뒤섞이지 않도록 면별 UV 방향과 회전을 보정했다.
- 스킨 선택 및 배치 방식은 저장되어 앱을 다시 실행해도 유지된다.

### 효과음과 화면 경험

- 큐브 회전 소리를 설정에서 선택할 수 있도록 기본, 말랑 팝, 실제 큐브, 끄기 모드를 추가했다.
- 실제 큐브 모드에는 CC0로 공개된 Rubik Cube 회전음 3종을 사용하고 출처와 라이선스를 문서화했다.
- 연습 화면의 불필요한 `2회`, `넓은 수` 버튼을 제거하고 주요 조작 버튼의 글자 크기와 배열을 정리했다.
- 스킨 미리보기, 연습, 배우기 화면에서 큐브 위치와 크기가 크게 어긋나지 않도록 카메라·레이아웃을 조정했다.

### 홈 큐브 선택 아이콘 핫픽스

- 홈 화면에서 3×3을 선택하면 컬러 큐브 그림이 별도의 흰색 큐브 그림으로 교체되던 문제를 수정했다.
- 2×2·3×3·4×4 모두 선택 후에도 원래 컬러 큐브 아이콘을 유지하고, 선택 상태는 파란 카드 배경으로만 구분한다.
- 세 크기를 차례로 선택해도 컬러 아이콘이 사라지지 않는 PlayMode 회귀 테스트를 추가했다.

## 사용 방법 및 확인 사항

- 3×3 큐브에서 힌트를 누른 뒤 표시된 수식을 왼쪽부터 순서대로 직접 입력하면 완성 상태까지 진행할 수 있다.
- 공식 중간에 힌트를 다시 눌러도 이미 수행한 동작은 다시 나오지 않고 남은 공식부터 이어진다.
- 표시된 공식과 다른 동작을 입력하면 기존 계획은 폐기되고, 다음 힌트에서 현재 상태 기준으로 경로가 다시 계산된다.
- 카메라 인식은 조명, 반사, 낡은 스티커에 영향을 받을 수 있으므로 촬영 결과의 중심색과 전개도를 확인한 뒤 연습을 시작한다.
