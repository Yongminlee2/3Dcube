# 실제 큐브 회전 효과음 출처

앱의 `실제 큐브` 효과음 모드에는 Freesound 사용자 **SpaceJoe**가 녹음한
`Rubik Cube Sounds` 묶음의 아래 세 파일을 사용한다.

| 앱 파일 | 원본 | Freesound ID |
|---|---|---:|
| `RubikTurn_06_CC0.mp3` | Rubik Cube Turn - 6 | 486582 |
| `RubikTurn_09_CC0.mp3` | Rubik Cube Turn - 9 | 486585 |
| `RubikTurn_25_CC0.mp3` | Rubik Cube Turn - 25 | 486578 |

- 묶음: https://freesound.org/people/SpaceJoe/packs/27490/
- 라이선스: **Creative Commons Zero (CC0 1.0)**
- 라이선스 원문: https://creativecommons.org/publicdomain/zero/1.0/
- 사용 파일은 각 Freesound 페이지가 공개하는 공식 HQ MP3 미리보기다.

CC0이므로 상업적 사용, 수정, 배포 및 공연이 허용되며 저작자 표시가 필수는
아니다. 다만 프로젝트 안에서 출처를 추적할 수 있도록 이 문서를 유지한다.
